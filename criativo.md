# Criativo Devs — Improvement Plan (Landing Page)

## 1. Problema Atual

A página apresenta:

* Estrutura simples demais
* Texto básico e sem proposta de valor
* Falta de foco no core business
* Ausência de seções que recrutadores/clientes esperam
* Visual sem personalidade de marca
* Zero diferenciação técnica
* Portfolio pobre em descrição, contexto e resultados
* Falta de CTAs fortes e direcionados

## 2. Objetivos da Melhoria

* Transmitir senioridade real (+5 anos, full stack, soluções escaláveis)
* Criar narrativa profissional sólida
* Aumentar conversão (vagas + freelancing)
* Fortalecer marca Criativo Devs
* Gerar confiança técnica imediata

## 3. Ações Recomendadas por Seção

### **Hero Section**

* Criar headline clara de posicionamento:
  “Full Stack Engineer especializado em Python, Django, React e soluções SaaS escaláveis.”
* Adicionar subheadline com foco empresarial:
  “Construo sistemas robustos, APIs de alta performance e aplicações mobile orientadas a negócio.”
* CTA duplo:

  * **Ver Portfolio**
  * **Contrate-me / Book a Call**

### **About**

* Expandir com narrativa orientada a impacto:

  * Principais entregas
  * Tipo de cliente
  * Resultados concretos (KPIs, melhorias, reduções de custo, performance)
* Separar em blocos:

  * “Quem sou”
  * “Minha abordagem técnica”
  * “Como entrego valor”

### **Portfolio**

* Cada projeto deve ter:

  * Nome do projeto
  * Stack usada
  * Problema resolvido
  * Resultado do projeto
  * Link para backend, frontend e mobile (quando existir)
  * Capturas de tela mais profissionais
* Adicionar de 4–6 projetos, não apenas 2.

### **Main Stack**

* Transformar em uma seção mais robusta com:

  * “Backend”
  * “Frontend”
  * “DevOps”
  * “Cloud (AWS)” — mesmo em aprendizado, posiciona melhor
* Colocar badges de senioridade (ex: “+5 anos”, “produção real”, etc.)

### **Contact**

* Melhorar copy:

  * “Entre em contacto para projetos, consultoria ou oportunidades profissionais.”
* Criar formulário com validação real e integração (Getform, AWS SES ou outro).
* CTA adicional: **Calendly link** (agenda automática).

### **Problemas Técnicos/UX a Corrigir**

* Padding e spacing inconsistentes
* Falta de hierarquia visual
* Fontes pequenas
* Botões pouco consistentes
* Falta de dark mode/light mode (mínimo aceitável hoje)
* Responsividade ainda fraca em várias partes

### **Branding**

* Criar identidade visual básica:

  * Paleta de cores
  * Tipografia padrão
  * Estilo de ícones
  * Versão horizontal e vertical do logo

### **SEO/Técnico**

* Melhorar meta tags
* Incluir OpenGraph
* Ajustar Semântica HTML (header, section, footer…)
* Adicionar um sitemap básico
* Google Analytics 4 + Search Console

### **Sessões a Adicionar**

* **Testemunhos** (mesmo que 2–3 colocados por colegas de trabalho)
* **Experiência profissional resumida** (como mini-CV)
* **Serviços** (o que ofereces comercialmente)
* **Case Studies** (alto impacto)

---

## 4. Prioridade (Roadmap 1–2 horas)

1. Reescrever Hero para algo forte e profissional
2. Expandir About com foco em resultados
3. Reorganizar Portfolio com descrição de cada projeto
4. Unificar UI (cores, spacing, tipografia)
5. Criar CTAs claros
6. Inserir meta tags e SEO básico

---

## 5. Entregáveis para o Copilot

* Reescrever seções
* Criar nova estrutura HTML/Tailwind
* Criar componentes reutilizáveis
* Melhorar responsividade
* Melhorar acessibilidade (aria-labels, contraste)
* Criar dark/light theme toggler

---

# Resultado Esperado

Uma landing page que transmite senioridade, profissionalismo, clareza técnica e foco no cliente.
Maior conversão tanto para vagas quanto freelancing.
Marca Criativo Devs mais forte e coerente.
